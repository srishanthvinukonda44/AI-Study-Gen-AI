# 📚 AI Study Buddy

An interactive **Generative AI learning assistant** that helps students study smarter.  
It can generate **flashcards, quizzes, and simplified explanations** from any notes you provide — powered by **OpenAI GPT‑4o Mini** and **Gemini 3.5 Flash APIs**.

---

## ✨ Features
- 📝 Paste your study notes and get instant AI‑generated learning material.
- 🎯 Generate flashcards for quick revision.
- ❓ Create multiple‑choice quizzes to test your knowledge.
- 💡 Simplify complex topics into easy explanations.
- 🌐 Frontend built with **HTML, CSS, JavaScript** (or Python frontend option).
- 🔗 Connects to **OpenAI** and **Gemini APIs** for generative responses.

---

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript  
- **Backend (optional)**: Python/Flask or Node.js (to securely proxy API requests)  
- **APIs**: OpenAI GPT‑4o Mini, Gemini 3.5 Flash  
- **Deployment**: GitHub Pages / Netlify / Streamlit
